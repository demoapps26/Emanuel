# Grupo Patrícia Pilar — Mundo 3D

Pacote de passagem para programação. Requisitos recolhidos em 22/10/2026.

## Estado real
Existe uma ideia definida, dados de 13 explorações e da sede, imagens aéreas fornecidas pelo utilizador e propostas visuais geradas. NÃO existe ainda aplicação jogável, repositório remoto criado ou integração de mapas implementada. Este pacote não contém uma aplicação pronta.

Este é um projeto novo e independente da app de gestão Estufas Patrícia Pilar e da CropLogic. Não usar credenciais, bases de dados ou alojamentos desses projetos.

## Como iniciar
Extraia este ZIP para a pasta do novo projeto, disponibilize essa pasta ao Codex e envie o conteúdo de 01_PROMPT_PARA_CODEX.txt. Os ficheiros já contêm o contexto necessário. Não assumir que outro chat conhece esta conversa.

## Ficheiros
- 01_PROMPT_PARA_CODEX.txt: instrução de execução inicial.
- 02_REQUISITOS.md: âmbito, fases, limites e critérios de aceitação.
- dados_exploracoes.json: dados estruturados fornecidos pelo utilizador.
- referencias/: 14 imagens aéreas de referência e propostas visuais, quando disponíveis.

As referências aéreas não são modelos 3D nem levantamentos topográficos. Os contornos desenhados servem apenas para identificar propriedade e não devem ser mostrados no resultado final. As imagens de conceito não demonstram qualidade gráfica já alcançada.
