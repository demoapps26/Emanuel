# Tomates do Oeste — conceito de visita digital

Protótipo visual em português inspirado na referência fornecida. HTML, CSS e JavaScript, sem dependências de compilação.

## Executar

Na pasta extraída do ZIP (ou em `/workspace/Emanuel/prototipos/visita-visual`):

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

A página inclui enquadramento por arrasto ou teclado, zoom, minimapa expansível, pontos de informação, partilha e som ambiente sintetizado. A imagem é ilustrativa; não há deslocação 3D, condução ou dados de exploração em tempo real. Os dados e a identidade visual precisam de confirmação antes de uma publicação comercial.

As fontes Google são opcionais: existem fontes locais alternativas. A imagem principal é servida localmente a partir de `assets/farm.png`.
